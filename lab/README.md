| 檔案 | 是什麼 | 狀態 |
|---|---|---|
| `map.html` | **色體圖**：中心一條線，每個群組一個方向，每件作品一條橫線，線越長完成度越高。右下角列出所有群組 | 首頁設定裡的「色體圖」就是嵌入這一頁 |

## 色體圖自己跑，不用登記

- 直接讀總列表 `decks.json`、`sites.json`。方向＝作品在首頁的群組，順序照 `groups.json`。
- 每個群組只畫**最新的 8 件**（照 `date`），數量改 `map.html` 的 `MAX`。新作品加進總列表就會自動出現，擠掉那個群組最舊的一條；舊的仍在「清單」模式和首頁其他陳列方式裡。
- 所以新作品一定要填 `date` 和 `group`。

## projects.json（選填）

- `tray`：頂端「手邊」放哪幾件，填作品 id。
- `works`：個別作品的補充，key 是作品 id：
  - `state`：`seed` 未開始、`doing` 進行中、`done` 完成（沒寫就是完成）、`live` 持續更新。
  - `progress`：0–10，決定線的長度；沒填就照 `state` 推估。
  - `next`：下一步，點進作品時顯示。
  - `who`：`self` 給自己看、`show` 給別人看（預設）。
